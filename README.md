# Wenqi — Personal Resume

A lightweight, bilingual resume page with responsive and print layouts. It is plain HTML, CSS, and JavaScript so GitHub Pages can serve it without a build step.

## Publish with GitHub Pages

Set the repository's Pages source to the `main` branch and `/` folder. The page will be available at `https://wwqicode-blkchain.github.io/wenqi-resume/`.

## Update the resume

- Edit `index.html` for Chinese copy and page structure.
- Edit `script.js` for the English copy.
- Edit `styles.css` for visual changes and print rules.
- Use the print button in the page to save a PDF.

This first version intentionally omits a phone number, email address, and exact employment dates because they were not present in the source materials reviewed. Education is summarized as provided; school names and degree dates can be added when the earlier resume is available.
